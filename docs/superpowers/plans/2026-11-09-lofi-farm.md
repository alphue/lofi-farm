# Lo-fi Gece Çiftliği Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser farm game where each plant adds a lo-fi music layer, plants grow in real time, and the game is playable from GitHub Pages.

**Architecture:** Static ES modules, no build step. Pure logic (`plants`, `state`, `moon`, `music`) is unit-tested with Node's built-in runner; browser-only code (`audio`, `render`, `main`) is verified by hand in the browser. Sound is synthesized with Web Audio (no sample files).

**Tech Stack:** HTML, vanilla JavaScript (ES modules), Canvas 2D, Web Audio API, localStorage, `node --test` (Node ≥ 20).

**Spec:** `docs/superpowers/specs/2026-11-09-lofi-farm-design.md` (Turkish). Visual reference: `docs/superpowers/specs/visual-style-sketches.html`, card C.

## Global Constraints

- No money, shop, quests, scores, accounts, server. No timers that punish; plants never die or wither.
- Every planted layout must sound consonant: all melodic notes come from the current chord of the fixed progression.
- Harvest never removes the plant: it drops to 50% growth and regrows; harvest may discover a new species.
- Unlocked species have unlimited seeds. 4 species unlocked at start, 8 total. Game never "ends".
- Growth is computed from timestamps, so it advances while the game is closed.
- Desktop-first; must load and be clickable on a phone browser.
- No dependencies, no bundler. Must run from `index.html` served statically (GitHub Pages).
- UI text in Turkish.

## Review Focus

1. Corrupt, empty, or older-version save in localStorage → game starts a fresh farm, no crash. (Task 2 test)
2. System clock moved earlier than a plant's `plantedAt` → growth is 0, never negative. (Task 1 test)
3. Player away for weeks → plants are simply mature (growth 1), no overflow. (Task 1 test)
4. Every tile planted with every species → combined voice gain stays ≤ 1, no clipping. (Task 4 test)
5. Audio before any user gesture → a "Başla" overlay starts audio on click; nothing plays or errors before it. (Task 5 manual check)

### Task 4: Music mapping (pure)

**Files:**
- Create: `src/music.js`
- Test: `tests/music.test.js`

**Interfaces:**
- Consumes: `COLS`, `growth` (Task 1), `SPECIES` (Task 1).
- Produces:
  - `export const BPM = 78, STEPS_PER_BAR = 8` (eighth notes), `stepSeconds() → number` (= 60 / BPM / 2).
  - `export const PROGRESSION` — 4 chords, one per bar, as MIDI arrays: Fmaj7 `[53,57,60,64]`, Em7 `[52,55,59,62]`, Dm7 `[50,53,57,60]`, Cmaj7 `[48,52,55,59]`.
  - `voicesAt(state, step, nowMs, fullMoon) → Voice[]`, `Voice = { idx, role, midi, gain }`. `step` is a global eighth-note counter; bar = `floor(step / 8) % 4`.

Rules `voicesAt` must follow:
- A tile contributes only if growth ≥ 0.1; its gain is `growth × roleGain` (chords 0.5, bass 0.6, bell 0.35, texture 0.25, hats 0.2, pluck 0.3, keys 0.4, pad 0.3).
- Each role has a fixed 8-step on/off pattern (builder's choice). The tile's column rotates the pattern by `col` steps; the tile's row picks the note: `chord[row % 4]` for melodic roles, transposed +12 for bell/pluck, −12 for bass. Texture and hats have `midi: null`.
- `pad` (moonflower) only sounds when `fullMoon` is true; on full moon every bell voice gets +12 extra (the "rare variation").
- After collecting voices, if the summed gain exceeds 1, scale every gain by `1 / sum`.

- [ ] **Step 1: Write the failing tests:**

```js
test('seedling under 10% is silent', () => {

test('every melodic note belongs to the current chord (any octave)', () => {
  const s = full();
  for (let step = 0; step < 32; step++) {
    const chord = PROGRESSION[Math.floor(step / 8) % 4].map(n => n % 12);
    for (const v of voicesAt(s, step, LATE, true))

    assert.ok(sum <= 1 + 1e-9);
  }
});

  assert.ok(steps.every(st => voicesAt(full(), st, LATE, false).every(v => v.role !== 'pad')));
  assert.ok(steps.some(st => voicesAt(full(), st, LATE, true).some(v => v.role === 'pad')));

```

### Task 5: Audio engine and start overlay

**Files:**
- Create: `src/audio.js`, `index.html` (minimal: canvas + "Başla" button + `<script type="module" src="src/main.js">`), `src/main.js` (temporary: start button → audio demo)

**Interfaces:**
- Consumes: `voicesAt`, `stepSeconds`, `BPM` (Task 4).
- Produces: `createAudio() → { start(): Promise<void>, schedule(voices: Voice[], whenSec: number): void, now(): number }`.

Requirements:
- `start()` creates/resumes the `AudioContext`; only called from the "Başla" click.
- Master chain: voices → lowpass (~3 kHz) → `DynamicsCompressorNode` → destination. Constant quiet ambience under everything: filtered noise (vinyl/cricket bed).
- One small synth per role (oscillator type + short envelope): chords/keys/pad = soft triangle/sine with slow attack; bass = sine; bell/pluck = short sine/triangle pluck; hats = short high-passed noise burst; texture = soft noise swell. Exact timbres are the builder's call; must sound soft, never harsh.
- Scheduler: look-ahead loop (e.g., every 25 ms schedule steps falling in the next 100 ms) using `ctx.currentTime`, not `setInterval` timing.
